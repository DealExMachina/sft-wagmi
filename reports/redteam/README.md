# Red Team Reports

This directory stores version-linked red-team guardrail reports generated by `eval_redteam.py`.

Expected structure:

```text
reports/redteam/
  v0.2.1/
    auth_redteam_20260416-101500.json
    auth_redteam_20260416-101500.md
    small_redteam_20260416-102030.json
    small_redteam_20260416-102030.md
```

Each report pair (`.json` + `.md`) is intended to be attached to a model version release
for robustness traceability (EU AI Act transparency and governance evidence).
